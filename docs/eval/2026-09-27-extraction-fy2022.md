# Extraction accuracy of the production pipeline — 2026-09-27

**Why this run exists.** ADR-0012 makes deltas decide what the watchlist surfaces,
so how often the extracted figures are wrong is load-bearing. Issue #45 required
measuring it before trusting a delta.

**What ran.** `multi` arm (the production pipeline: research → risk → compliance),
`claude-sonnet-4-6` (the production model), dataset `e6-2026-09-19`, the
`correct_extraction` cases for FY2022 onward — 35 cases, 19 companies, fields
revenue / net income / EPS / gross margin. Local vector store; production untouched.

    PGVECTOR_URL= python eval/run_full.py --arm multi --category correct_extraction --since 2022

Raw scorer output: [`2026-09-27-extraction-fy2022.report.json`](2026-09-27-extraction-fy2022.report.json).

agent *didn't* report as a miss, and one field (EPS) is never reported at all.

## What went wrong, by cause

1. **EPS is never fetched — 32 omissions (product).** The historical-financials
   tool emits revenue, net income and gross margin per fiscal year but no EPS,
   and synthesis is told never to invent a figure, so it correctly leaves
   historical EPS as "—". Consequence for the watchlist: EPS deltas can only
   ever come from analyst *estimates*, never from reported results.

2. **Answer-key fiscal-year mislabel — 7 "wrong" figures (eval dataset).**
   `generate_dataset.py` pulls SEC frames by *calendar* year (`CY2024`) and labels
   them `FY2024`. Identical for December year-ends; off by one for January
   year-ends: CY2024 is Walmart's and NVIDIA's own **FY2025**. The agent reported
   their actual FY2024 and was marked wrong (Walmart ×4, NVIDIA ×3 — every error
   for both companies, all a consistent one-year shift).

3. **Losses read back as profits — 2 figures (product).** `agent/brief_parser.py`
   drops the sign for `-$2.22B`, `($2.22B)`, `–$2.22B` and `−$2.2B`, and reads
   `$(2.22)B` as 2.22. Boeing FY2023 (−$2.22B) and 3M FY2023 (−$7.0B) were stored
   as profits. The same parser feeds watchlist deltas, where a swing from loss to
   profit would show as no change.

4. **Which revenue line — 5 figures (definitional).** Exxon ("sales and other
   operating revenue" vs "total revenues and other income"), JPMorgan ×2 (reported
   vs managed net revenue, 1–2% apart), Pfizer ×2 (the brief matches the
   reported total; the answer key's XBRL concept is a narrower line). Not misreads,
   but a sign that "revenue" needs one defined source.

5. **Unexplained — 1 figure.** Caterpillar FY2024 EPS reported $19.06 vs $22.05.

**Escalations (2):** Walmart FY2022 and Microsoft FY2022 — the research tools
return a company's latest four fiscal years, and for January/June year-ends that
window already starts at FY2023. Compliance refused to ship an unsourced brief,
which is the intended behaviour. Earlier FY2019–2021 cases escalate the same way
and were excluded from this run as out of the product's scope (briefs cover
FY2022–FY2027E).

## What this means for trusting a delta

- Revenue, net income and gross margin deltas are trustworthy to roughly the
  88% level, and **the agent does not invent numbers**.
- **Loss-making companies were not safe** until the sign fix lands (#3).
- **EPS deltas on reported results do not exist** until EPS is fetched (#1).
- "Citation correctness" is not measured: briefs cite source types, not accessions.
